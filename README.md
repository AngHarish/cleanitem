# Clean Item Mod (Fabric)
A minimalist Minecraft server/client utility mod

# Introduction
Clean Item does only three things: clear dropped items, switch to daytime, and switch to clear weather. No extra features, no config files—works out of the box.

# Features & Keys

Delete — Clear all dropped items in the current world

\ — Set time to daytime

- — Set weather to clear

# Installation
Install the Fabric loader
Put the downloaded jar into .minecraft/mods
Launch the game

# Notes
Clearing dropped items is irreversible. Please use with caution.
Appropriate permissions are required on multiplayer servers.
